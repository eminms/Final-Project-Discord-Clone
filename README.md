# Discord Clone - Full Stack Web Application

##  About the Project
This is a full-stack web application inspired by Discord, developed as a final project. 
The project aims to replicate core communication functionalities, demonstrating server-side logic and client-side integration.

##  Technologies Used
* **Back-End:** C#, ASP.NET Web API
* **Front-End:** JavaScript, HTML, CSS
* **Database:** SQL Server

##  Key Features
* RESTful API architecture for data processing.
* Interactive and responsive User Interface.
* Seamless communication between Front-End and Back-End.
